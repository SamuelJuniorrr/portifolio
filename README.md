# Portfólio | Samuel Ferreira

Site estático multipágina (HTML/CSS/JS, sem build). Publique na raiz do repositório e ative o GitHub Pages na branch `main`.

- `index.html`, `projetos.html`, `projeto.html?id=...`, `sobre.html`, `contato.html`
- Projetos: edite `data.js` (arrays `PROJ` e `MORE`)
- Contato: o formulário usa FormSubmit. No primeiro envio, o e-mail de destino recebe um link de ativação; clique nele uma vez.
- WhatsApp e LinkedIn: constantes no topo de `app.js`
